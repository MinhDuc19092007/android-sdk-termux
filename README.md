

# android-sdk-termux

Custom Android SDK, NDK, and CMake tailored for Termux.

⚠️ **Note: Repository Required**

This package is not available in the default Termux repositories. You **must** add the **TermuxVoid** repository to your `sources.list` before attempting to install this package.

## 🚀 Installation

Once you have added the TermuxVoid repository, update your sources and run the following command:

```bash
apt install android-sdk -y
```
